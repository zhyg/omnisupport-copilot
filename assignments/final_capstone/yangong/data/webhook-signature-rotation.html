Northstar Workspace Webhook 签名失败与双密钥轮换

文档版本 1.0，适用于 Workspace 3.2–4.2。内部错误码 WS-WEBHOOK-401；常见响应为 HTTP 401。本文档仅包含课程合成数据。

诊断

先在投递日志中核对请求标识、发送时间、签名算法和 HTTP 401，再确认消费者使用原始请求体计算 HMAC。JSON 重新序列化、字符集转换或代理改写都会改变摘要。

处理步骤

  1. 使用投递日志中的请求时间检查五分钟时钟偏差门禁，并拒绝过期请求，防止重放。
  2. 在不记录密钥和完整载荷的前提下，比较签名版本、摘要长度及请求标识；密钥只从受控 secret store 读取。
  3. 轮换时先让消费者同时接受 current 与 next 两把密钥，验证一条测试投递成功后再提升 next，最后撤销旧密钥。

控制边界

支持坐席可以查看脱敏投递元数据并添加内部备注。创建、展示、轮换或撤销签名密钥需要 support lead 审批；方案卡不得自动执行这些动作。

成功标准

同一请求标识在允许时间窗内只被接受一次，测试投递返回 2xx，旧密钥撤销后无法通过校验。
